## 🛡️ О клиенте JustVPNchik

**JustVPNchik Client** — фирменное приложение для быстрого и безопасного подключения к серверам нашего VPN-сервиса.

### ✨ Главные преимущества:
* 🚀 **Умный Сплит-туннель (Обход сайтов РФ)**:
  Российские сайты и сервисы (**Wildberries, Ozon, Авито, Сбер, Т-Банк, ВТБ, Госуслуги, VK, Яндекс, Кинопоиск, 2ГИС, доставка и зона `.ru`/`.рф`**) открываются **напрямую на максимальной скорости**. Заблокированные ресурсы (Instagram, YouTube, Discord, ChatGPT и др.) идут через наши защищённые серверы JustVPNchik.
* ⚡ **Высокая скорость**: Оптимизирован для протокола **VLESS Reality** и ядра xray-core.
* 🎨 **8 стильных цветовых тем**: Персонализация подсветки и адаптивного фона.
* 🇳🇱 **Точный мониторинг**: Определение стран серверов, индикаторы пинга и задержки.
* 📊 **Учёт трафика**: Отображение использованного трафика и времени сессии в реальном времени.
* 🪟 **Автозапуск**: Бесшумная работа в системном трее при включении ПК.

## 🚀 Как подключиться:

1. Скопируйте ссылку на вашу подписку формата:
   `https://justvpnchik.duckdns.org:8000/sub/...`
2. Откройте приложение и нажмите кнопку **«Буфер»** (или вставьте ссылку через «Вручную»).
3. Нажмите большую кнопку **Подключиться** 🛡️.
