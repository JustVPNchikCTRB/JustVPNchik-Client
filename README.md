=== JustVPNchik v1.1.0 ===
Быстрый и надежный VPN-клиент на базе xray-core

Файлы в этой папке:
1. JustVPNchik-Setup.exe — Установщик программы (создает ярлык на Рабочем столе и в меню Пуск).
2. JustVPNchik-Portable.exe — Портативная версия (запуск в один клик без установки).

Возможности:
• Сплит-туннель: Прямой быстрый доступ к сайтам РФ + надежный обход блокировок для остальных.
• Поддержка всех современных протоколов: VLESS, VMESS, Trojan, Shadowsocks, Hysteria2.
• 8 стильных цветовых схем подсветки и адаптивного фона.
• Автозапуск с Windows и тихий режим работы в системном трее.
